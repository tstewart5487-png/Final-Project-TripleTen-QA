# Contributing

Thanks for your interest in contributing to this QA portfolio. Suggested contributions include adding screenshots, recordings, or expanding test cases with additional edge cases.

How to contribute

1. Fork the repository and create a feature branch named `feature/<short-description>`.
2. Make your changes and include screenshots or evidence in an `assets/` folder where relevant.
3. Open a pull request with a clear title and description of the change.

Reporting bugs

- This repo contains QA deliverables that reference Jira tickets. For issues with the test reports themselves (typos, missing evidence), open a GitHub issue.

PR review checklist

- Does the change include necessary evidence (screenshots/video) where applicable?
- Are test steps reproducible and clear?
- Does the change include updates to the README or docs when appropriate?
